# Uganda NCDC CBC Grading System — Complete Reference
### For Shule Developers · Based on UNEB & NCDC Official Sources

---

## 1. Overview

Uganda's National Curriculum Development Centre (NCDC) rolled out the **Competency-Based Curriculum (CBC)** for Lower Secondary (S.1–S.4) in 2020. The first cohort sat the Uganda Certificate of Education (UCE) under this system in 2024. It completely replaces the old Division 1–4 / Grade 1–9 system.

The core philosophy shift: assessment is no longer about **what a learner knows** — it is about **what a learner can do** with what they know. Grades describe competency levels, not rank positions.

---

## 2. Assessment Structure

Every subject final grade is derived from two components combined:

| Component | Weight | Who Administers |
|-----------|--------|-----------------|
| Continuous Assessment (CA) | **20%** | School teacher |
| End-of-Cycle Examination | **80%** | UNEB (national exam) |

Additionally, **Project Work** is assessed separately and appears as a standalone component on the certificate. It does not feed into the subject letter grade.

---

## 3. Continuous Assessment (CA) — The 20%

### 3.1 What CA Measures

CA is a **systematic, comprehensive, and cumulative** process of gathering information on a learner's achievement across three learning domains:

| Domain | Taxonomy Used | What It Measures |
|--------|---------------|------------------|
| **Cognitive** | Bloom's Taxonomy | Knowledge, understanding, application, analysis, evaluation, creation |
| **Psychomotor** | Dave's Taxonomy | Physical skills — imitation → manipulation → precision → articulation → naturalization |
| **Affective** | Krathwohl's Taxonomy | Values, attitudes, behaviours — receiving → responding → valuing → organization → characterization |

### 3.2 CA Instruments

Teachers use four instruments to conduct CA:

1. **Continuous Assessment Framework (CAF)** — guides which competencies to assess per subject, per class, per term
2. **Continuous Assessment Items (CAI)** — stimulus items that prompt learners to demonstrate competency in a real-life context
3. **Observation Checklist** — the tool teachers use to record what a learner demonstrated
4. **Project Assessment Tool** — for project work (separate from subject CA)

### 3.3 The Observation Checklist — How Scoring Actually Works

This is where the **0–3 scoring** originates.

For each competency being assessed, the Observation Checklist lists **indicators** — specific observable behaviours that prove a learner has acquired the competency. The teacher observes the learner and ticks each indicator they see demonstrated.

The **level of ability** at which the learner demonstrates the competency determines the score:

#### Psychomotor Domain (Dave's Taxonomy)

| Level | Score | What the Learner Does |
|-------|-------|----------------------|
| **Naturalization** | **3** | Performs the skill with ease, minimal mental effort, automatically and fluently |
| **Articulation** | **3** | Uses multiple methods creatively and accurately |
| **Precision** | **2** | Performs independently without support, with minimal errors |
| **Manipulation** | **1** | Follows instructions to perform the skill |
| **Imitation** | **1** | Observes and replicates — copies after a teacher or recording |
| **Not demonstrated** | **0** | No indicators observed / learner absent |

#### Affective Domain (Krathwohl's Taxonomy)

| Level | Score | What the Learner Does |
|-------|-------|----------------------|
| **Characterization** | **3** | Consistently demonstrates the value/behaviour as a defining characteristic |
| **Organization** | **3** | Actively advocates and influences others to adopt the behaviour |
| **Valuing** | **2** | Demonstrates the behaviour independently |
| **Responding** | **1** | Reacts to information — asks questions, discusses |
| **Receiving** | **1** | Takes in information — reads, listens, observes |
| **Not demonstrated** | **0** | No indicators observed / learner absent |

#### Cognitive Domain (Bloom's Taxonomy)

| Level | Score | What the Learner Does |
|-------|-------|----------------------|
| **Creating / Evaluating** | **3** | Produces new work, justifies decisions, evaluates solutions innovatively |
| **Analysing / Applying** | **2** | Draws connections, uses knowledge in new situations |
| **Understanding / Remembering** | **1** | Explains concepts, recalls facts |
| **Not demonstrated** | **0** | No evidence / absent |

> **Key rule:** A score of **0, 1, 2, or 3** is awarded per competency — never a fraction. The score reflects the **highest level of ability demonstrated**, not a count of ticks.

### 3.4 CA Score Calculation

Each subject has multiple competencies assessed per term (C1, C2, C3...). Each competency is scored 0–3.

```
Total Points   = sum of all competency scores (e.g. C1 + C2 + C3 + C4 + C5)
Max Points     = number of competencies assessed × 3
CA out of 20   = (Total Points / Max Points) × 20
```

**Example:**
- 5 competencies assessed (C1–C5)
- Scores: 3, 2, 3, 1, 2 → Total Points = 11
- Max Points = 5 × 3 = 15
- CA out of 20 = (11 / 15) × 20 = **14.67**

## 4. End-of-Cycle Examination — The 80%

- Set and administered by **UNEB** (Uganda National Examinations Board)
- Taken at the end of S.4 (end of the 4-year lower secondary cycle)
- Score is **out of 80**
- Tests competencies using construct-based assessment items aligned to the CBC

---

## 5. Final Subject Score Calculation

```
Final Total = CA out of 20 + Exam out of 80
```

**Example continued:**
- CA out of 20 = 14.67
- Exam out of 80 = 58
- Final Total = **72.67** → rounds to 73

## 6. Letter Grade Scale (Official UNEB CBC Scale)

| Grade | Score Range | Grade Points | Descriptor |
|-------|-------------|--------------|------------|
| **A** | 80 – 100 | 5 | Exceptional |
| **B** | 70 – 79 | 4 | Outstanding |
| **C** | 60 – 69 | 3 | Satisfactory |
| **D** | 50 – 59 | 2 | Basic |
| **E** | 0 – 49 | 1 | Elementary |

> **Important:** There is **no failure grade**. Every learner receives a grade from A to E. Grade E (Elementary) still describes competencies the learner has acquired — it does not mean the learner failed.

### Grade Descriptors (Official UNEB Wording)

| Grade | Full Official Descriptor |
|-------|--------------------------|
| A — Exceptional | Demonstrates extraordinary competency by applying knowledge and skills **innovatively and creatively** in real-life situations |
| B — Outstanding | Demonstrates a **high level** of competency by effectively applying acquired knowledge and skills in real-life situations |
| C — Satisfactory | Demonstrates an **adequate level** of competency in applying knowledge and skills in real-life situations |
| D — Basic | Demonstrates a **minimum level** of competency in applying knowledge and skills in real-life situations |
| E — Elementary | Demonstrates **elementary** competency — the learner has begun acquiring knowledge and skills but application is limited |

## 7. Grade Points and Transcript Reporting

Grade points (1–5) are used for **overall subject aggregation** on the transcript — not for calculating the subject grade itself.

```
Subject grade points:  A=5, B=4, C=3, D=2, E=1
Overall performance = sum of grade points across all subjects
```

The UNEB transcript shows:
- Letter grade per subject
- Grade points per subject
- Total grade points
- Result classification (Result 1 = qualifies for certificate, Result 2 = does not qualify)

> A learner qualifies for the UCE certificate (Result 1) if they have achieved at least a **D** in the required number of gradable subjects.

| End of Term Examination | `end_of_term` | Summative — contributes the 80% | — |

| Assignment | `assignment` | Take-home work | — |

> Only **End of Term Examination** scores feed directly into the 80% exam component. All other assessment types feed into the 20% CA component.

## 9. The calcCBC() Function — Shule Implementation

```typescript
export function calcCBC(
  totalPoints: number,   // sum of competency scores (each 0–3)
  assessed: number,      // number of competencies assessed
  examOutOf80: number    // raw end-of-term exam score out of 80
) {
  if (assessed === 0) throw new Error('assessed cannot be zero')

  const maxPoints = assessed * 3
  const outOf20 = Math.round((totalPoints / maxPoints) * 20 * 100) / 100
  const total = Math.round((outOf20 + examOutOf80) * 100) / 100

  const grade =
    total >= 80 ? 'A' :
    total >= 70 ? 'B' :
    total >= 60 ? 'C' :
    total >= 50 ? 'D' : 'E'

  const gradePoints =
    grade === 'A' ? 5 :
    grade === 'B' ? 4 :
    grade === 'C' ? 3 :
    grade === 'D' ? 2 : 1

  const descriptor =
    grade === 'A' ? 'Exceptional' :
    grade === 'B' ? 'Outstanding' :
    grade === 'C' ? 'Satisfactory' :
    grade === 'D' ? 'Basic' : 'Elementary'

  return { maxPoints, outOf20, total, grade, gradePoints, descriptor }
}
```

### Usage example

```typescript
// Student has 5 CA competencies scored: 3, 2, 3, 1, 2
// End of term exam score: 58 out of 80
const result = calcCBC(11, 5, 58)

// result = {
//   maxPoints: 15,
//   outOf20: 14.67,
//   total: 72.67,
//   grade: 'B',
//   gradePoints: 4,
//   descriptor: 'Outstanding'
// }
```

## 10. What Appears on the Report Card

Each subject row on the CBC report card must show:

```
Subject: Mathematics

Continuous Assessment (20%)
  C1: 3/3   C2: 2/3   C3: 3/3   C4: 1/3   C5: 2/3
  Total: 11 / 15   →   CA Score: 14.67 / 20

End of Term Examination (80%)
  Exam Score: 58 / 80

Final Total: 72.67 / 100
Grade: B — Outstanding
Grade Points: 4
```

## 11. Key Rules for Shule UI

1. **CA competency score inputs** must be a segmented control or select with exactly four options: **0 / 1 / 2 / 3** — never a free number input or percentage field

2. **Score distribution charts** must draw the pass/fail reference line at **50** (the D/E boundary)

3. **Grade labels** must use exact UNEB wording: Exceptional / Outstanding / Satisfactory / Basic / Elementary — never Pass/Fail

4. **Missing CA scores** block report card generation — UNEB excludes candidates with missing CA (they receive Result 2). Shule must warn when CA is incomplete before the Secretary can generate a card

5. **Project Work** is a separate score on the certificate — Shule tracks it separately and it does not feed into `calcCBC()`

6. **No ranking** — the CBC system explicitly eliminates learner ranking between schools. Shule must never show a class rank or school rank derived from CBC grades
